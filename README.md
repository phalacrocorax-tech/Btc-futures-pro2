# BTC Futures PRO

Uma calculadora avançada de BTC Futuros, com suporte para **Long e Short**, cálculo automático de **preço médio**, **ponto de liquidação**, **gráficos Recharts** e **gestão automática**.

Esta app foi desenvolvida com **React + Vite** e pode ser deployada facilmente usando o Vercel.
